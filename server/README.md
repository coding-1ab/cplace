## Endpoints (GET)

### 1. Get Chunk Image (Live / Not Tested)

Retrieves the current state of a chunk as a PNG image. The image is generated by scaling the 64x64 grid to 256x256 (4x scale). If the chunk does not exist, a blank (black) chunk is returned.

*   **Method:** `GET`
*   **Path:** `/get/get_pixel_png/<chunk_x>/<chunk_y>/<zoom_lv>`

#### Parameters
*   `chunk_x` (Integer): Global X coordinate of the chunk.
*   `chunk_y` (Integer): Global Y coordinate of the chunk.
*   `zoom_lv` (Integer): Zoom level (currently unused/placeholder).

#### Response
*   `200 OK`: Returns the generated PNG image (`<chunk_x>_<chunk_y>.png`).
*   `500 Internal Server Error`: Error reading chunk data or generating PNG.

---

### 2. Get Sample Drawing (Static Test)

Returns a static sample PNG for testing purposes (hardcoded pattern).

*   **Method:** `GET`
*   **Path:** `/mock/get_pixel_png/<chunkx_>/<chunky_>/<zoom_lv>`

#### Parameters
*   `chunk_x` (Integer): Global X coordinate of the chunk.
*   `chunk_y` (Integer): Global Y coordinate of the chunk.
*   `zoom_lv` (Integer): Zoom level (currently unused).

#### Response
*   `200 OK`: Returns the sample PNG image (`<chunk_x>_<chunk_y>.png`).
